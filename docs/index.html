Er liest deinen LIVE-Chat mit, erkennt Beleidigungen, Hass, Belästigung, Spam und wichtige Fragen, und sagt dir oder deinem Moderator sofort, was zu tun ist.

✅ Läuft in deiner eigenen Cloud, auch wenn du nur mit dem iPhone streamst und dein PC aus ist.
✅ Keine Installation, kein Programmieren.
✅ Kein TikTok-Passwort nötig, niemals.

Dauer: ca. 15 Minuten, einmalig. Am besten direkt hier auf dem iPhone in Safari.

1 KI-Schlüssel holen

  1. Auf „Anthropic öffnen“ tippen und registrieren.
  2. Billing → Guthaben kaufen (5 USD reichen für Monate). Tipp: unter Limits ein Monatslimit setzen, z. B. 10 USD.
  3. API Keys → Create Key → Name „Live Moderator“ → kopieren. Der Schlüssel beginnt mit sk-ant- und wird nur einmal angezeigt.
Anthropic öffnen

Behandle den Schlüssel wie ein Passwort und schick ihn niemandem.

2 Eigenen Server starten

  1. Auf „Server bei Render starten“ tippen, registrieren (E-Mail, Google oder GitHub) und eine Zahlungsmethode hinterlegen.
  2. Bei ANTHROPIC_API_KEY deinen Schlüssel aus Schritt 1 einfügen.
  3. Deploy Blueprint bzw. Apply antippen und 3–8 Minuten warten, bis der Status Live zeigt.
  4. Auf deine Adresse tippen (sieht aus wie https://fmm-live-moderator-xxxx.onrender.com).
Server bei Render starten

Alle Sicherheitsschlüssel werden für deinen Server automatisch neu und zufällig erzeugt.

3 Moderator übernehmen & einrichten

  1. Deine Adresse zeigt „Willkommen bei deinem eigenen Live Moderator“. Namen eingeben → Moderator übernehmen. Das geht nur einmal, in den ersten 6 Stunden.
  2. Sofort sichern: Safari → Teilen → „Zum Home-Bildschirm“. Das ist ab jetzt dein persönlicher Zugang.
  3. Dem Assistenten folgen: TikTok-Name → Regeln → KI → Verbindung testen → Bot aktivieren.
  4. Die angezeigte Wortliste in den TikTok-Schlüsselwortfilter kopieren.
🎉 Fertig! Ab jetzt startet der Moderator bei jedem LIVE automatisch.

❓ Häufige Fragen

Schaltet der Bot Störer selbst stumm?

Nein. TikTok bietet dafür keine offizielle Schnittstelle. Der Bot empfiehlt, und du oder dein TikTok-Moderator führt es mit zwei Fingertipps aus. Wörter aus deiner Wortliste blendet TikTok automatisch aus.

Ich streame nur mit dem iPhone. Wie sehe ich die Hinweise?

Trag eine Vertrauensperson in TikTok als LIVE-Moderator ein und schick ihr den Moderator-Link aus deiner App (Einstellungen). Sie sieht alles live. Oder nutz ein zweites Gerät. Nach jedem LIVE gibt es einen Bericht.

Zugang verloren?

Render → dein Dienst → Environment → Wert von ADMIN_TOKEN kopieren → deine-adresse.onrender.com/admin öffnen → Schlüssel eingeben → „Neuer Link“.

Wie kündige ich?

Render → dein Dienst → Settings → Delete Service. Damit enden alle Kosten und die Daten werden gelöscht. Bei Anthropic den Schlüssel löschen.

Was passiert mit den Chat-Daten?

Sie liegen nur auf deinem eigenen Server und werden nach 30 Tagen automatisch gelöscht. Zur Prüfung gehen nur Kommentartext und Anzeigename an die KI von Anthropic.
